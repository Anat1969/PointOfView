# Faces

אפליקציית ווב בעברית לניהול סשנים עם קלפי פנים והשתקפויות. המנחה מעלה תמונות פנים ומזין מילות השתקפות. בכל סשן, אישי או קבוצתי, המנחה שולף קלפים אקראיים, מחליף ורושם הערה לכל קלף, ושומר. יש גם תצוגה מלאה לקבוצה.

## דפים

| כתובת | דף |
|---|---|
| `#/` | דף הבית: טבעת קלפים תלת־ממדית, סשן חדש, ספריות, היסטוריה |
| `#/faces` | ספריית פנים: העלאת JPG או PNG, מחיקה, רשת. עד 99 פנים |
| `#/reflections` | ספריית השתקפויות: עד 50 מילים ועוד 8 קלפים ריקים, יחד 58 |
| `#/session/:id` | סשן: שליפת פנים, השתקפות או זוג, החלפה, הערה לכל קלף, סיכום ושמירה |
| `#/present/:id/:n` | תצוגת קבוצה: גלגל קלפים בעומק. חיצים, F למסך מלא, N להערות, Esc לחזרה |
| `#/history` | היסטוריה: פתיחה, שכפול, מחיקה, ייצוא JSON ו-CSV |

## הרצה

```bash
npm install
npm run dev        # פיתוח
npm run build      # בדיקת טיפוסים ובנייה
npm run preview    # שרת על הבנייה, פורט 4173
npm run test:e2e   # בדיקת Playwright מול preview (דורש preview פעיל)
node scripts/make-icons.mjs   # יצירת אייקוני האפליקציה מחדש
```

## הנחות (הכרעה פשוטה, שורה לכל אחת)

- תמונות נשמרות ב-IndexedDB, כי localStorage מוגבל לכ-5MB. שאר הנתונים נשמרים ב-localStorage.
- כל תמונה מוקטנת ל-1000 פיקסלים לכל היותר ונשמרת כ-JPEG. מגבלת קובץ: 15MB.
- "58 מילים, 8 ריקות" פורשו כ-50 מילים ועוד 8 קלפים ריקים. מספר הריקים ניתן לשינוי בין 0 ל-8.
- קלף ריק: המשתתף בוחר מילה בעצמו, והשורה הראשונה בהערה מוצגת כמילה על הקלף.
- סשן נשמר להיסטוריה רק בלחיצה על "שמירה". עד אז הוא טיוטה, וגם היא נשמרת במכשיר.
- בהחלפת קלף ההערה נשמרת, כי לרוב היא נכתבה על השאלה ולא על התמונה.
- השתקפות נשמרת בסשן כתמונת מצב של המילה, כדי שעריכת הספרייה לא תשנה סשנים ישנים.
- בתצוגת קבוצה, חץ שמאלה מתקדם (כיוון קריאה מימין לשמאל).
- שמות קבצי הייצוא באנגלית ובתאריך, כי חלק מהדפדפנים מחליפים שם בעברית ב-"download".
- הנתונים מקומיים בלבד, בלי שרת. קישור שהועתק עובד רק במכשיר שבו נוצרו הנתונים.
- תלת־ממד ב-CSS ו-framer-motion, בלי three.js: קל יותר, וטקסט בעברית נשאר חד.
